DASH 安装说明（轻量版，约 5 分钟）
==================================
本包为轻量版（约 2MB），使用你电脑上的 Node.js，需要先装 Node。
（想要"开箱即用、不用装 Node"的，请下载完整版 DASH-macOS-full.zip）

【第 1 步】安装 Node.js（必须，一次性）
  打开 https://nodejs.org
  点绿色的 LTS 版下载 → 双击安装包 → 一路"继续"直到装完。
  （用 Homebrew 装过 node 的，还需要 brew install npm）

【第 2 步】放好 App
  解压本压缩包 → 把 DASH.app 拖进"应用程序"文件夹。

【第 3 步】首次打开
  如果系统提示"无法验证开发者 / 已损坏"，二选一：

  方式一（图形界面，最简单）：
    右键 DASH.app → 选"打开" → 弹出提示后再点一次"打开"。

  方式二（终端命令，一劳永逸）：
    打开"终端"，粘贴执行：

      xattr -cr /Applications/DASH.app

    这行命令是清除 macOS 给"从网上下载的文件"打的隔离标记（quarantine）。
    （提示：如果提示没有权限，命令前面加 sudo，回车后输入开机密码）

【第 4 步】填 API Key（可选）
  第一次启动会自动下载 dsh（需要联网，约 2 分钟），
  然后可能弹出输入框：粘贴你的 DeepSeek API Key 点"保存"，或直接点"取消"。
  两种都会继续，不填也不影响使用。
  （想要 key 的话：platform.deepseek.com → API Keys 里创建一个并复制，
   之后在 dsh 的设置页或菜单「设置 API Key」里随时可以添加）

【以后】
  双击 DASH 就能直接用，秒开。
  关掉窗口只是"隐藏"（不是退出），dsh 还在后台跑着；
  需要时点菜单栏右上角的 🐶 图标即可唤回窗口。
  要真正退出：点 🐶 图标 → "退出 DASH"。

注意：仅支持 Apple 芯片 Mac（M1 / M2 / M3 / M4），不支持 Intel Mac。
